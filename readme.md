# Monorail El Jojo - Iron Chemistry Ultimate

A small, browser-based interactive challenge for practicing iron chemistry reactions with مونوريل الجوجو

## Visiting the page

- Open `https://wala3.github.io/Eljojo` in a browser.

## Project files

- `index.html` - the challenge interface, styles, and game logic.
- `fe-sound.mp3`, `luxus.mp3`, `zero.mp3` - sound effects used by the challenge.
- `zizo-fail.jpg` - image shown for a failed reaction.
